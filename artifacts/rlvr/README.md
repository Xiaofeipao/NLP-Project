# RLVR 非权重证据

独立RLVR试验完成64次LoRA更新，训练采样256条路径；开发集五次检查均为0/40成功，未进行测试推理。完整解释见 [实跑报告](../../docs/rlvr_run.md)。

`dev_*.json` 保存逐条开发集预测与奖励，`rollouts.jsonl` 保存训练采样和梯度目标记录，`reload_check.json` 保存重载一致性及模型身份；`provenance.json` 保存配置、固定划分清单和源码来源，绝对路径已规范化。`source/` 保存实际运行的RL训练新增源码，既有依赖对应提交 `8e05270`，不代表后续合并代码已重新训练。`manifest.json` 校验导出数据和源码，不包含本说明文件。

不包含模型权重、缓存或完整本地输出目录；本地生成底座和新adapter仍是重新训练/推理所需依赖。该证据包可核查已有预测，不能声称单独下载后即可加载新模型。
