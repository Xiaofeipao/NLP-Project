# Top3、软循环惩罚与删环：完整因子消融

固定回退36步，完整比较三因素的8种开关组合，另有108→36评分预算对照。共四种反馈×302条错误案例×9配置=10872条输出，GPU重新计算R动作评分；冻结同一权重与既有模型V诊断，无新训练。

## 可比性

全部8组固定合法动作过滤、36新增动作上限和108评分状态上限；无Top3时仅1分支，最多实际使用36个评分状态，不能声称实际计算量相同。额外budget36组检查Top3预算敏感性，不参与8组合选优。T0P0E0不是原始Part2 R：它仍保留回退36步和合法动作过滤。模型valid不触发R；错误步号/非法保留前缀只拒绝，不用真实首错纠正。

开发候选50条按成功率、最优率、较少评分、较少功能选优，测试不重新选型。四反馈选择：模型/词表仅软惩罚，终点增强/执行器保留全部三个功能。纯模型轻量组测试成功率与完整版一致，但最优率较低，不能称其在所有指标上更好。配置见part3/best_r_factorial.json。旧的终点增强与执行器主方案无需替换。

## 主要发现

1. 删环在每一对案例上均未改变成功率/可行率，不能宣传为提高修复成功率；闭环删除保持终点，可增加最优路线数。
2. 软惩罚提升本轮总体成功率，但新增成功路径不一定最短；仍需Top3/删环改善路径质量，不能断言所有未知分布都受益。
3. Top3对最终成功率的增益依赖是否已有软惩罚；两者叠加后本轮候选成功率常相同，Top3主要改善最优率。
4. 全部开启仍是终点增强/执行器反馈下开发集最好的组合。减少评分预算在开发上使终点组82%→80%、执行器100%→98%，虽本轮测试恰好相同，仍保留原108预算。

## 审计与局限

10872条逐例输出通过官方执行器交叉检查；汇总由保存输出独立重算，全部开启组逐项复现上一轮K36成绩。原始测试已被多轮探索，本轮结果属于探索性消融，不能证明对未知分布必然提高正确率。V诊断未改，V准确率/定位率不会因为这些R组件变化而提升。逐例压缩记录、源码快照、GPU账本、配对gain/loss均保留；只推荐开发集胜出配置，其他组合不设为主入口。无新权重，未push。
