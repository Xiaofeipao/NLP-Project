# 障碍附近训练与多最优动作监督

本轮又实际训练了两个固定候选，并在开发集与上一版比较。由开发集选择多最优动作监督模型后，才运行测试；没有根据测试结果重选或追加调参。原始 Flan-T5/BART 基线和上一版逐步策略权重均未覆盖。

## 本轮修改

开发集中，上一版逐步策略的 25 个失败环境全部是障碍碰撞。因此本轮围绕这一问题组合修改了输入和采样：

- 输入额外明确列出 up/down/left/right 的即时状态：free、hits obstacle 或 outside wall，避免只靠合法动作列表的缺项来表达危险。
- 在同一训练网格中抽取可达非目标状态；训练采样有 50% 的机会优先抽取朝目标移动会碰到障碍的状态。本轮 2,000 条策略监督中有 1,003 条由该分支采样。开发监督均匀采样，不做困难样本过采样。
- 保持每个源 example ID 对应一行，仍是 2,000 条动作监督加 2,000 条验证，共 4,000 条。没有跨 split 移动环境或增加测试训练样本。
- 动作损失改为四动作分类，验证仍使用文本损失；按样本平均，避免验证文本 token 数较多而支配策略监督。动作预测只使用首个 decoder 位置，不训练策略生成整段路径或 EOS。

在相同输入和采样上比较两个损失，构成一项聚焦消融：single 强制一个固定最优动作；multi 以所有同样最短的合法动作构成目标集合，最大化该集合的总预测概率，而非强制一个任意的 BFS 顺序。

两者均从相同预训练 Flan-T5-small commit 开始，seed 42、两轮、batch 8、梯度累积 2、学习率 1e-4、500 次参数更新。每个候选有单独 pilot，预算全部进入共用 GPU ledger。新旧损失的归一化不同，不能通过 loss 数值直接断言谁更好。

## 开发集选择

在相同 98 个唯一开发起终点上，不使用移动 mask 或搜索的成功率：上一版 74.49%，single 81.63%，multi 84.69%。按预先写入脚本的规则，以无搜索成功率、约束成功率、无搜索最优率依次比较，选择 multi，并冻结权重和开发指标哈希。没有给两个新候选分别查看测试成绩后再挑选。

## 相同 200 个测试环境的结果

- 无搜索逐步策略：成功率从上一版 76% 提高到 **85%**，可行性由 76% 提高到 **100%**，最优率由 76% 提高到 82.5%。本轮没有碰撞或越界，剩余 30 个失败均在 36 步上限前未到目标，存在重复访问。
- 仅加合法未访问动作约束：成功率从 95% 提高到 **97.5%**，最优率从 85.5% 提高到 86.5%。
- 新的神经并列排序 A*：成功率 **100%**，最优率 **100%**。其中最优性来自显式搜索规则，不能称作模型独立推理。
- 前缀执行后由无搜索策略续写：ID 与 OOD 修复成功率均由 86% 提高到 **90%**。

并非所有指标都提升：约束修复在 ID 上从 97% 降为 96%，OOD 上仍为 96%。所有方法及逐条执行记录均保留在结果中，没有只保存有利指标。

## 搜索最优性修正与强对照

旧神经搜索把动作负对数概率加进边代价，可能为了高模型分数选择更长路径。本轮新增 `optimal_search_plans`：主优先级始终是实际步数 g 加 Manhattan 距离 h；神经累计分数只用于相同 g+h 的并列排序。对于当前静态四邻接网格，h 一致且可采纳，所以搜索保留单位步数最优性。预算耗尽仍返回失败，绝不使用隐藏最短路兜底。

在同一个新模型上，旧加权边代价方法成功率 100%、最优率 99%；新方法两者均 100%。上一版交付的加权方法最优率为 99.5%。

同时加入强纯 A* 对照，在 g+h 相同的情况下优先 h 更小的节点。测试中：神经并列排序平均展开 5.045 个状态，原普通纯 A* 为 8.26，强纯 A* 为 4.795。因此不能声称神经搜索比经过合理排序的纯 A* 更高效，也不能将较少的模型调用状态等同于墙钟更快。实际可靠规划可以直接选择纯 A*；本 NLP 实验有意义的提升主要是无搜索策略从 76% 到 85%。

## 使用与产物

默认规划入口现在优先读取 `config.policy.best.json`，指向开发集选中的 multi 模型和最优性保持搜索：

```powershell
conda activate torch_py311
python scripts/plan_grid.py --grid examples/grid.json
python scripts/plan_grid.py --grid examples/grid.json --method state_policy
python scripts/plan_grid.py --grid examples/grid.json --method legal_mask_no_search
python scripts/plan_grid.py --grid examples/grid.json --method symbolic_astar_goal_tiebreak
```

示例已实际运行，默认方法输出 `left left down left left`，执行成功。明确指定 `--config config.policy.json` 仍可使用上一版权重。

- 新模型：`outputs/planning_v3/multi/flan_t5_small/train/best/`。
- 全部候选开发比较、选中模型的 ID/OOD 结果和完整性检查：`outputs/planning_v3/results.json`。
- 固定选择：`outputs/planning_v3/selection.json`。
- 原始训练与评估日志：`outputs/planning_v3/logs/`。
- 状态监督构造：`ppnl/policy_v3_data.py`。
- 分类与集合损失：`ppnl/modeling.py` 的 action_set_loss。
- 推理和最优性保持搜索：`ppnl/policy.py`。

复用现有阶段和重新生成汇总：

```powershell
python scripts/run_policy_v3.py
python scripts/summarize_policy_v3.py
```

独立复现实验应使用新的输出和数据目录，不覆盖已冻结结果。两个候选共用相同策略数据文件；原测试候选逐字节不变。训练标签可使用 BFS，推理输入不包含距离图、参考路径或参考下一动作。

## 验证与限制

26 项回归测试通过，新增测试包括多个最优动作标签、集合损失的有限梯度、验证行全零动作 mask 的数值稳定性、以及极端神经分数仍不能改变 A* 最短步数。还用 79 个随机可达网格核查了 A* 的最优性。

这是同一批已多次评估的 200 个网格上的改进，不是新盲测；本轮候选选择只看开发集。只运行一个 seed，没有测试更大网格。ID/OOD 的网格相同，所以规划指标相同；OOD 的错误数量差异只在候选修复中体现。输入增强、困难状态采样和归一化是组合变化，仅 single 与 multi 的差异是被单独控制的消融，不能把组合提升分别归因于每个组件。
