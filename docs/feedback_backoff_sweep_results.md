# 新R回退1–36步：GPU扫描结果

## 结论

已跑1..36，共4种反馈、302条错误案例（开发候选50、开发G失败23、ID100、OOD100、G失败29），43488条输出。只变回退步数，Top3、108评分预算、软循环惩罚、最终删环和同一权重均固定。不训练，复用冻结V诊断，GPU重新评分R。

按开发候选50条的成功率、最优率、评分成本、更小K依次选优：模型2步、词表1步、终点2步、执行器2步。测试不用于重新选择K。开发选优配置保存在part3/backoff_sweep_selection.json，仅作消融。

短回退没有超过原36步的测试质量：不替换现有best_rollback.json；已有K36继续作为稳定增强R方案。这个稳定性决定不是从本轮测试扫描中挑出另一个最高K，旧方案原先已有开发选择记录。
