# 第一部分 第二项和第三项的逻辑关系

## 术语与版本

`FirstPart`为同伴第一部分基线分支，引用提交f00fbdf。我们的`part2`实现GVR，`part3`比较改进与消融；它们对应课程Part 2中的第2项和第3项，不能与课程Part 3“报告展示”混淆。

本分支不合并FirstPart整条历史。其训练代码以固定源码快照提供，方法、指标和开发选择仍引用同伴正式证据。全项目旧Flan-T5-small/C4/A*成绩属于其他模型与设置，不能拼入本轮主表。

## 第一部分提供什么

同伴比较三模型，用开发集选出Flan-T5-base第2轮作为主模型；BART-base第2轮是第二比较模型，不是必须串接在主模型后面的独立V。主模型本身可执行动作预测和验证两项任务。数据为2,000状态动作例加2,000验证例，开发200条，ID/OOD各200候选、地图配对，按障碍布局隔离。

FirstPart主模型ID直接生成成功84.5%、可行100%、最优84%；验证ID Macro-F1 48.13%、首错定位8%，OOD分别66.37%、23%。全部31条生成失败为合法但未到目标，模型全误接受。这是“生成有一定能力、验证无法可靠发现失败”的证据。

同伴文档明确将原局部规则修复结果降为历史记录，正式修复方案待定。因此本轮不是把其历史规则修复偷偷当正式基线，而是明确提出新的反馈引导续走，并在同一R下补足反馈比较。

远端没有可见的该轮主模型LFS权重路径，经用户授权按相同预训练revision/数据/seed/两轮协议独立复现。开发选第2轮，本地生成成功85.5%、最优85%；与同伴84.5%之差是不同权重复现的差异，不能当Part2改进。

## Part2 从失败诊断到反馈实验

G：微调主模型逐步给动作评分，最多36步。V：模型诊断或符号执行器诊断。R：读取诊断的valid/invalid和首错位置，保留首错前缀，再由同一微调动作策略续走，最多36个新增动作。它没有完整文本R监督，reason文本不进入动作策略；不是自动补路算法或最短路缩短S。

固定候选中，使用模型反馈的raw R修复成功率ID20%/OOD28%，准确执行器反馈为94%/92%。说明反馈诊断准确性会影响修复。但本地自生成的29条失败均为循环/未到目标，只有准确诊断仍不能使无访问记忆的策略脱离循环，完整成功仍85.5%。

据此形成两个可测试瓶颈：V要能发现未到目标；R要能避免重复走同样的循环。词表与终点校验修正部分诊断，合法动作/最少访问约束修正动作选择。2×2消融中，只改V或只改R均85.5%，两者结合98.5%；最优率仍85%，因此成功提升不等于最短规划提升。

## Part3 比较替代方案与保留方法

七类代表方案固定为21配置，三个训练分支包含等预算普通追加训练控制。所有训练/提示/恢复配置在本轮推理前定义，先运行开发集选优，再运行固定ID/OOD矩阵。开发排序优先完整成功，其次候选修复、最优率、验证联合准确率，并列保留较早简单配置；不按测试挑冠军。

研究选择保留terminal_visit：开发生成191/191、无效候选41/50；测试生成197/200、原非法候选ID/OOD各78/100。迭代无额外收益，CoT未产生合规FINAL格式，输入表示增强未超过等追加训练控制，辅助分类损失ID有收益但OOD不稳定。全部保留作消融。

总体控制排序中，完整执行器V加同一visit R候选修复100%/100%，生成98.5%。老师允许规则V/R，这可作为工程默认；模型V仍是研究对照，不能写其分类/定位达到100%。移除R模型评分、保留同一V与访问规则的uniform控制为生成96%、修复64%/63%，说明评分相对该控制有用；仍缺预训练与微调前后匹配对照，也不能据此声称优于所有强规则。

## 能回答什么

本设置中，准确反馈改善固定错误候选的修复；对于自生成循环，准确验证和恢复动作约束需要协同。研究收益包含明确符号贡献，模型没有因此被证明理解详细reason或具备全局最优规划。

全部为单seed、已使用测试集上的探索性结果。没有运行可选7×7/密集6×6，也未用第二模型重复全部改进（题目允许省略）。GPU预算、训练谱系遍数和提示表示增强口径均在协议中披露。
