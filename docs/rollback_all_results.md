# 增强 R 全范围回退扫描

CPU完成，对每条错误候选枚举0至整段前缀的所有位置，并统计全局K=0..36。续走固定为Top3、软循环惩罚、最终闭环删除，最多36新动作、108个状态评分。不新增训练，不物理重跑G/V。

## 与诊断误差和分岔的关系

离线记录模型诊断步与真实首错步的偏移，并用“已走步数+当前位置到终点最短距离是否大于起点最短距离”定位首次失去最优可能的动作。这样允许多条最短路径，避免拿单条BFS路线当唯一正确答案。生产选择只读取反馈、前缀可执行性和循环，不读取此最短路标签；oracle_reference单独标注，既不参与选择，也不保证R性能是上界。

前置较小矩阵增加了模型反馈和普通visit恢复对照。模型V将生成29条失败全判valid，回退无法自行启动；若增加前缀程序校验，必须把该额外规则收益与改变K分开记录。原Part2完全忠实对照见 [普通R回退](part2_rollback_results.md)。
