# 类别分布与捷径学习实验

## 数据诊断

以 GitHub StepVerification-v1-v2@9eeb494 和本组上一轮 Prompt 对照的原模板权重为来源。先核对训练输入是否带有答案、样例 ID 或与输出绑定的固定标记，再做同语义换格式、同格式换语义两类测试。所有模型均为文本输入，未引入坐标计算特征或执行器结果覆盖。

| V 训练标签 | v1，2,000 条 | v2 独立 V，2,000 条 |
| --- | ---: | ---: |
| valid | 1,000 · 50.00% | 1,589 · 79.45% |
| goal_not_reached | 589 · 29.45% | 0 |
| invalid_action_token | 200 · 10.00% | 200 · 10.00% |
| obstacle_collision | 139 · 6.95% | 139 · 6.95% |
| out_of_bounds | 72 · 3.60% | 72 · 3.60% |

v2 还在 2,000 条 G 记录上加入权重 0.5 的停止辅助监督，全部为未完成。它不在独立 V 的上表中。

原 NewPart1 的整路径 V 训练也具有与 v1 相同的五类计数。其合法候选平均 5.55 个动作，未到目标平均 3.25 个动作，所有训练路线最长 14 个动作。后来生成失败中的 36 步循环明显超出该训练长度范围。因此，错误类型不均衡、候选长度迁移和局部监督覆盖需要同时检查。v1 的 valid/invalid 二分类数量原本各 1,000 条，不能简单称为二分类不平衡。

v1 的 58 条 null 输入全部未完成。v1 和 v2 的全部 200 条非法动作样本都使用 jump。方向词和标签也有关联，例如 v2 带方向词的训练大多是 valid；真实逐步验证又会大量问到合法但尚未到目标的状态。原始训练输入未出现样例 ID，重复输入也未发现互相冲突的目标。Prompt 的说明段本来同时列举所有错误标签，说明段中出现标签字符串本身不是逐例泄漏。现有证据指向数据分布与任务监督覆盖造成的偏置。

只使用训练集的“动作词→最常见目标文本”映射，在完全不读当前坐标、目标、尺寸和障碍列表的情况下，v1 训练得到的映射在固定单错和双错上获得 55.59%／73.33% Macro-F1，v2 映射为 52.38%／73.33%。未知词确实与非法动作有关，这个词汇判断是任务的一部分。但仅靠它可以获得较高的汇总分，不能据此认定模型理解了几何状态。

## 原模型的语义与格式测试

从开发布局构造 200 对，共 400 条局部询问，分别只改目标、加一个障碍、改变当前行使动作越界、将 STOP 从目标处换到未完成位置。每种 50 对，每对真标签不同。训练时没有使用这些布局或语义对。检查每对是否两个都答对，也看两个输入得到的模型回复是否完全相同。

原 Prompt 对照权重在原格式下，目标对、障碍对、边界对、停止对各 50 对，均为 0 对两边同时正确。目标对和障碍对的 50 对回复全部相同。它在单错和双错候选上 Macro-F1 为 52.38%／73.33%。这些结果比单看汇总分更直接地暴露出对语义变化不敏感的问题。

另将完全相同的信息改为字段逆序、多行或重排组合，原模型在固定候选上分数变化不大。这个结果与上轮完整模板交叉实验不同：本轮保留原指令、字段名和任务说明，仅重排输入字段及障碍顺序。轻微排版变化与整段指令换模板需要分别评估。

## 受控训练

冻结同一个 NewPart1 Base，只训练文本 V 的 q/v rank-8 LoRA，alpha 16，学习率 3e-4，有效 batch 16。各组两轮、250 次更新，按同一开发规则选轮次。开发规则同时看原格式和重排格式的固定候选与 G 输出。原来的 125 更新入选模型也保留作为历史对照。本轮重新训练一个对照，确保新选模规则在各组一致。

| 组 | 变化 |
| --- | --- |
| 原数据重新训练对照 | 原 GitHub v1 的 2,000 条、原模板、原损失。 |
| 原数据＋类别重加权 | 同一条数据和顺序，按五类逆频率加权每例损失。 |
| 均衡数据 | 2,000 条，每类 400。valid 和未完成各有 200 条 STOP、200 条动作。各种相反标签共享相同格式、训练地图和动作词；非法词由 jump 扩展为 8 种。 |
| 均衡数据＋格式增强 | 与均衡组完全相同的数据和答案，混入原字段顺序、逆序、多行三种格式。 |
| 均衡数据＋格式增强，seed 43 | 同一数据配方，另一个训练种子。 |

均衡数据重新分配了监督内容，结论对应整套等量数据配方。类别重加权与原数据对照则只改变每个类别的损失系数。没有更新 G 和 R。推理继续采用原分支逐步扫描和局部规则 R。

## 开发结果触发的二级均衡补充

第一轮开发阶段，五类等量和五类等权损失都明显倾向 invalid。五类各 20% 时，valid 总体只有 20%，四类 invalid 合计 80%。因此保留这组负结果，再串行加入二级均衡对照，避免反复依据测试成绩修改同一组模型。

二级类别重加权让原 1,000 条 valid 的权重保持 1，四个错误类别各累计 250 的权重质量。另一套重建数据保留总数 2,000，valid 1,000、其余四类各 250。valid 分为已到达 STOP 和合法到达动作各 500；未到目标分为 STOP 和动作各 125；非法词、碰撞、越界各 250。同样比较原格式、混合格式及后者 seed 43。每组保持两轮、250 次更新的预算。补充实验与首轮共用冻结的底模和开发选择规则。

两轮均衡的全部模型在原格式以及两种信息不变的重排格式下，四类反事实测试均为 0/50 对两边同时正确。部分模型对成对输入产生了不同回复，但改变后的回复也不正确。该结果没有证明学到了这些几何和停止语义。

多数均衡模型在四批真实 G 路线上把失败检出，但 R 修好数均为 0。原权重所暴露的定位和原因问题仍在。重建训练分布的做法也使模型大量误拒成功路线，例如二级均衡＋格式增强在旧 H100 G 的 170 条合法路径上误拒 146 条，seed 43 为 144 条。

本轮所有局部 R 结果均未修坏原有合法路线。有些错误候选修好数高于对照，这是更多 invalid 输出使更多路径触发了规则 R。它可以增加系统成功数，但验证误拒、成对语义及真实 G 修复不支持把这些权重当作语义能力更强的 V。

## 能得出的结论与后续

1. **错误内部存在长尾与输入绑定。** 五类表应和 valid/invalid 的二分类表一起看。v1 二分类本已均衡，按五类平均可能反而使 invalid 的损失质量过高。
2. **没有发现样例 ID 或逐例答案占位符泄漏。** 固定指令段对各标签相同。关键的分布问题包括 jump 对单一类型的完全绑定、null 缺正例、普通动作缺未完成语义、位置与障碍关系没有被当前文本模型学会。
3. **存在模型对语义变化不敏感的实测证据。** 对完全相同动作和格式，只改变目标、障碍或边界，应该改变答案的成对样本依然不能同时答对。动作词多数映射可得到较高 Macro-F1，所以需要把这些成对指标和主测试成绩同时报告。
4. **本轮九组训练没有产生能稳定替换原 V 的文本模型。** 原数据二级加权保持成绩，其余方案大多降低 Macro-F1。数据配方变化比单纯重加权包含更多因素，结果适用于本次 2,000 条、两轮、250 更新的 LoRA 配方。不能据此断言其他预算或其他模型都无法学习。

下一轮若继续改文本 V，应先在开发成对测试上确认模型能对「只改目标」「只改一个障碍」作出正确翻转，再扩展为整条路径评测。保持二分类均衡的同时，更明确监督一步动作后的状态、位置是否在图内、候选格是否被占用和是否到达；用该中间任务的无／有对照测收益。格式增强可用于稳住表达变化，但本轮未显示它能替代这些语义能力。上轮结构化 V 的高分有额外的数值状态与地图特征，本轮没有加入那些特征。
