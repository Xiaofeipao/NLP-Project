# 后续方法候选（尚未实现或运行）

依据本地复现，C4 成功 184/200、最优率 43%，规则 H4 成功 200/200、最优率 99.5%。优先解决死路和绕路，而不是继续堆叠没有有效奖励差异的 CoT/GRPO。以下为项目适配建议，论文结果不代表我们项目已经有提升。

1. **带回溯的有限预算搜索**。保留暂时未选中的分支，在当前 beam 全部死路时回到备选状态。与 C4 固定总 decoder-row/token 预算比较，不只匹配 beam 宽度。参考 [Policy-Guided Search on Tree-of-Thoughts](https://arxiv.org/abs/2601.03606) 的策略引导和查询预算思路；我们的网格适配不是论文复现。已有 policy.py 的 A* 与 best-first 应优先复用，不重复实现搜索框架。
2. **路径代价与模型概率的组合排序**。在同一约束解码器中加入明确的步数成本、曼哈顿启发和 LM 分数，开发集选权重，保留纯 LM/纯规则/组合三组。目标是改善最优率，不能把规则贡献说成模型能力；该建议来自本项目 C4/H4 差距，并非论文已验证结论。
3. **过程监督或局部修复监督**。用独立训练地图的合法动作和距离进展提供密集标签，先确保监督训练产生有效回答，再研究 RL。参考 [Rewarding Progress](https://arxiv.org/abs/2410.08146)，其关键是衡量未来成功的进展，而非仅判断当前动作是否合法；网格中的 BFS 距离奖励只是项目特定适配。训练标签可用 BFS，但不能悄悄把真实距离作为模型推理输入。需先审计 4000 条配额和剩余训练遍数。

补充低成本诊断：打乱/移除修复反馈，保持 G 候选、R 权重及解码预算不变，判断当前提升是否主要来自约束而非反馈理解。前缀修复已有旧实验，应比较新约束 R 下的反馈消融，避免重复旧结论。[Query-Efficient Planning](https://arxiv.org/abs/2412.06162) 研究反馈式整体规划与启发搜索的交互成本，为记录模型/执行器调用提供参考。

可靠 NO_PATH 可以单独加 BFS 可达性门控，属于显式算法增强；作为系统对照，不冒充模型学习结果。所有候选先开发集，冻结后再评估；历史重复测试集上的改善只能作为探索性结果，不用它反复调参。
