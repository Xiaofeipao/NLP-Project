# 执行器奖励强化学习试验

## 方法与范围

本轮响应 RLHF 尝试，实际采用 RLVR：目前没有人工偏好标注，没有训练人类偏好奖励模型，因此不能称为完成了严格意义的 RLHF。使用原 GVR 候选生成底座，独立训练 q/v LoRA，不修改原 checkpoint。

实现为单次 on-policy REINFORCE 更新：同一网格采样四条完整路径，以其余三条的平均奖励作为 leave-one-out baseline；使用 token 平均策略梯度与冻结底座的采样 KL 估计项。不使用 PPO clipping、多轮旧样本更新或 critic，不冒充完整 GRPO。组相对奖励思路可参照 [DeepSeekMath 原论文](https://arxiv.org/abs/2402.03300)，本项目实现与其算法有上述区别。

奖励定义：成功为 `2 + 1/(1+动作数)`；失败为 `0.5×曼哈顿距离进展比例 − 非法动作惩罚1 − 0.01×动作数`。失败路径的进展只计算首个非法动作前的位置；可行但未到目标不计成功。曼哈顿距离不是障碍地图的真实剩余最短距离，塑形存在偏差，不能用奖励增长替代任务成绩。奖励不读取参考路径，采样路径通过本地严格执行器并与官方执行器校验。

## 已完成运行

- seed=42；从现有训练集 generation 子集均匀抽样，有放回。
- 64 次更新、每组4条，共256条采样路径，涉及60个不同训练样本 ID；训练采样中2条成功，67条可行。
- 学习率0.00005；LoRA r=8、alpha=16、dropout=0；KL beta=0.02；梯度范数上限1。
- 采样 temperature=1、top_k=0、top_p=1，最多48个新 token。没有合法动作掩码、搜索或参考路径兜底。
- 每16步在固定40条 generation 开发集上贪心解码；按成功率优先、平均奖励其次选模型。训练前对照也采用相同48-token上限，与历史128-token结果不是完全相同的解码条件。
- 64组奖励均有差异，存在策略梯度信号。不能把同一组的256条采样当成256个独立环境。

开发集成功率在 step 0/16/32/48/64 均为 **0/40**。平均奖励依次为 −1.169055、−1.167555、−1.159555、−1.158805、−1.148805。最终依据次级奖励选中 step64，**没有观察到开发集规划成功率改善**。这是单种子小规模探索试验，不证明 RL 无效，也不能宣称总体能力提升。

选中 LoRA 已从磁盘重新加载，40条开发集预测与保存记录逐字一致。训练和重载均计入共用 GPU ledger。原模型、原评测目录及历史报告保持原样。未进行测试推理；划分审计读取测试文件的 ID/布局属于结构校验，不将测试样本作为训练或选模输入。

## 代码与产物

本轮可核查的非权重证据已收录于 [artifacts/rlvr](../artifacts/rlvr/README.md)：包括逐条采样、五次开发集预测、重载检查和规范相对路径的来源记录，manifest 提供文件校验和。原始训练基于提交 `8e05270` 及归档的RL新增源码；后续合并的训练修复不能倒算作本轮已运行代码。新权重继续仅保留本地。

- `ppnl/rlvr.py`：奖励、leave-one-out advantage 和带采样 KL 的策略目标。
- `scripts/run_rlvr.py`：数据审计、CUDA训练、逐组轨迹、开发集选模及独立LoRA保存。
- `scripts/verify_rlvr.py`：重载选中的 LoRA，在相同开发集核对预测。
- `configs/rlvr.json`：独立试验超参数和输出路径。
- `tests/test_rlvr.py`：成功/非法/长度奖励排序、等回报零优势、策略梯度方向和padding屏蔽。
- `outputs/rlvr_reinforce_001/`：本地权重、逐条rollout、各次开发集预测、身份哈希和重载检查；机器可读摘要见 [rlvr_run.json](rlvr_run.json)。

输出目录拒绝覆盖。复现实验须复制配置并使用新目录；GPU命令应串行执行。当前脚本只支持 train/dev，不提供测试评测入口。后续若评测，应先扩展冻结机制以绑定RL adapter及其推理设置，不能沿用原G/V/R锁冒充已冻结。此前生成的旧源码冻结锁也会因新增代码而失效，这是预期的漂移检测行为。

若继续研究，应预先声明后续训练预算，并比较相同预算的SFT续训/不训练对照；若要做真正RLHF，则另需独立人工偏好采集、标注准则与奖励模型验证。不能把执行器自动偏好称为人类标注。技能图仍是独立消融计划，HotpotQA未接入。
