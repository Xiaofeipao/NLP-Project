# 可选地图泛化评测集（v1）

本目录为**项目合成数据，不是官方直接下载的样本**。已构造并完成 CPU 真值检查，尚未运行模型。生成脚本：`scripts/build_generalization_dataset.py`，固定 seed `20261112`。

- `test_7x7.jsonl`：200 个互不重复的障碍布局。按原训练样本的障碍数量分布抽样，再按面积 49/36 缩放并取整；实际含 1、3、4、5 或 7 个障碍。密度近似匹配，不能声称是完全隔离其他因素的纯尺寸消融。
- `test_dense_6x6.jsonl`：200 个互不重复的布局，每图随机 9–12 个障碍，占全部格子的 25%–33.33%。原训练图为 1–5 个障碍。
- 每组都有 50 条最短合法候选、50 条绕路合法候选、100 条单错误非法候选。100 条非法候选的替换、删除、插入、提前终止、非法动作各占 20 条；提前终止是一处截断操作，不保证 token 编辑距离等于 1。

每个 JSONL 行是一张地图加一个验证候选，与 `derived/test_id.jsonl` 格式一致：复用 `evaluation_subsets` 可得到 G=200、V=200、R=100；这不是 500 张独立地图。两组合计 400 张新地图、400 条候选，均有 BFS 最短路径和执行器真值。输入地图采用随机障碍和随机自由起终点，拒绝不可达与最短路少于 2 步的情况；因此本集合不衡量 `NO_PATH` 识别能力。

## 防泄漏与冻结

排除 `derived`、`policy_v2`、`policy_v3` 的全部已知布局及 manifest 中保留的布局分区；新两组布局也互不重叠。布局身份不包含起终点，避免同一障碍图换起终点后混入测试。原训练 4,000、开发 200、ID/OOD 各 200 的内容和配额不变。

`manifest.json` 记录来源字节哈希、生成器/执行器哈希、新数据哈希及抽样规则。这是数据快照，**不是模型实验冻结记录**。模型运行前须另行固定 checkpoint、方法、代码、解码预算和汇总指标；不要用本集合挑选超参数，也不要覆盖历史实验锁或将成绩混入旧 200 环境结果。7×7 是否仍固定 36 动作或按面积扩展上限，必须在运行前声明并对所有比较方法一致执行。当前旧测试入口只接受 ID/OOD，未将新文件偷偷接入旧冻结实验。

本集合只用于可选额外评测，不参与训练或开发选模。最短路径与诊断标签仅供评分/规定的反馈步骤使用，不可输入生成器作为答案提示。数据构造使用现有 BFS、候选扰动和官方/本地执行器交叉检查，无 GPU 或模型调用。

## 复现

从项目根目录运行（输出目录必须不存在）：

```powershell
python scripts/build_generalization_dataset.py --output outputs/generalization_rebuild
python -m unittest discover -s tests -p test_generalization_dataset.py
```

比较新文件与本目录 `files_sha256` 即可验证逐字节复现。测试还检查全部候选标签、参考最短路、布局隔离、旧数据未变，以及禁止覆盖已有输出。
